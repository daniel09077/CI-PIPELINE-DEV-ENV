
# JAVA-BASED-CI-PIPELINE-USING-DOCKER-CONTAINERS

A complete CI/CD development environment designed to automate the software delivery lifecycle from source code commit to artifact deployment.

The project built on Ubuntu OS integrates GitHub, Jenkins, Maven, SonarQube, Nexus Repository, Docker, and Tailscale to create an automated pipeline where code changes trigger Jenkins, the application is validated and tested with Maven, code quality is analyzed with SonarQube, and successful build artifacts are deployed to Nexus.

The project also explores webhook-based automation, credentials management, artifact repositories and containerized infrastructure.

## Project Tool Box:

**Git & GitHub:** Git manages local source code versions, while GitHub hosts the remote repositories and triggers CI/CD automation via webhooks.

**Docker:** Containerizes the application and pipeline tools to ensure environment consistency across deployment stages.

**SonarQube:** Performs static code analysis to ensure code quality and identify security vulnerabilities.Nexus: Serves as an artifact repository manager to store and version build dependencies and binaries generated by Maven.

**Tailscale:** It was particularly useful because the CI/CD infrastructure was hosted in my homelab and accessed remotely via SSH. 

**Jenkins:** CI/CD automation server used to orchestrate the pipeline, automate builds and tests, perform SonarQube analysis, and deploy Maven artifacts to Nexus.

### Docker 
**Run the following command to install docker on the ubunutu host.**:\
* **Update the ubunutu package manager:**\
    ```bash 
    apt-get install -y && apt-get upgrade 
    sudo apt install ca-certificates curl gnupg 
    ```
* **Add Docker's GPG Key:**\
First, create the directory where APT stores trusted repository keys:
    ```bash
    sudo install -m 0755 -d /etc/apt/keyrings
    ```
* **Download Docker's signing key:**  
    ```bash 
    sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
    ```

**Break it down:**

- curl: Downloads data.\
-fsSL: 
f → fail if the request fails
s → silent mode
S → show errors
L → follow redirects
-o Save output to a file.

**Change the permission of the key file:** 

```bash
    sudo chmod a+r /etc/apt/keyrings/docker.asc
```
**Meaning:**
"Allow all users/processes to read this key."

* **Add Docker Repository:**

**Now we tell Ubuntu:** \
    ```bash 
echo deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \ $(. /etc/os-release && echo ${UBUNTU_CODENAME:-$VERSION_CODENAME}) stable" | \ sudo tee /etc/apt/sources.list.d/docker.list > /dev/null 
    ``` \
  **Whats happening here?** \
deb

 |
Architecture
 |
 |
Trust this key
 |
 |

 |
 |

 |
 |
stable channel
- Confirm apt can now see the docker community repo using 
```bash 
    sudo apt update 
```
- install the engine:

**Run:**
``` bash
 sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

**Whats happening here:** 
- **docker-ce:** stands Docker Community Edition, this is the main Docker Engine. The daemon that manages containers.
- **docker-ce-cli** The command-line tool:
- **docker-buildx-plugin**: Provides advanced image building capabilities.
- **docker-compose-plugin**: This allows us to use docker compose

Confirm successful installation using *docker --version* and 
*sudo systemctl status docker - confirm docker service running*
